# apps/landing — лендинг «Траектории»

Презентационная страница продукта на собственном домене
**https://traektoriaedu.ru/**. Это не часть мини-приложения: мини-приложение
открывается только внутри MAX, а лендинг — обычный сайт для жюри, школьников
и родителей. Все кнопки ведут в бота [@t356_hakaton_max_bot](https://max.ru/t356_hakaton_max_bot).

Тексты, цвета, шрифты и экраны — из [прототипа](../../docs/prototype/index.html)
и [docs/screens](../../docs/screens). Композиция по мотивам sferum.ru: градиентный
hero, лист контента поверх него, шаги, блок доверия, вопросы.

## Запуск

Сборки нет — это статика. Любой статический сервер из этой папки:

```bash
python3 -m http.server 5180 --directory apps/landing
```

## Тесты

```bash
node --test apps/landing/landing.test.mjs
```

Без зависимостей, на встроенном `node:test`. Ловят то, что в статике ломается
тихо: файл, на который ссылается страница, отсутствует; якорь ведёт на удалённую
секцию; у картинки нет `alt` или размеров; кнопка ведёт не в нашего бота;
подключён скрипт или стиль с чужого домена; контраст токенов в светлой или
тёмной теме ниже 4.5:1 (ТЗ §12). Те же тесты гоняют CI и выкладка.

## Что где лежит

| Файл | Что это |
| --- | --- |
| `index.html` | вся разметка и тексты |
| `styles.css` | токены (блоки `/* tokens: light */` и `/* tokens: dark */` читает тест контраста), вёрстка, движение |
| `main.js` | прогрессивное улучшение: плашка шапки, проявление блоков, вкладки |
| `assets/screens/` | экраны из `docs/screens` в WebP |
| `assets/fonts/` | Onest и Unbounded, кириллица и латиница (SIL OFL 1.1) |
| `assets/og.png` | превью ссылки 1200×630 для мессенджеров |

**Без JS страница работает целиком.** Скрипт ставит класс `js` сам, поэтому, если
он не загрузится, скрытые до появления блоки не останутся невидимыми, а панели
«Что умеет навигатор» просто пойдут списком.

**Движение.** Один авторский момент — вход hero: лесенка вырастает, экраны
выезжают. Остальное — тихое проявление при прокрутке. При
`prefers-reduced-motion` всё статично.

**Экраны меняются вместе с `docs/screens`.** Пересобрать WebP:

```bash
cwebp -q 80 -alpha_q 90 -m 6 docs/screens/C1.png -o apps/landing/assets/screens/C1.webp
```

## Выкладка

При слиянии в `master` с изменениями в `apps/landing/` воркфлоу
[Deploy landing](../../.github/workflows/deploy-landing.yml) прогоняет тесты
и заливает папку в бакет `traektoriaedu.ru` (кроме тестов и README).
Бакет, DNS и сертификат создаёт Terraform (`infra/terraform`), пайплайн их
не трогает. У файлов нет хеша в имени, поэтому ассеты кешируются на час,
`index.html` — без кеша.
