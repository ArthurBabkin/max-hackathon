# packages/shared/texts

Словарь текстов с двумя вариантами на ключ: `kid` — ученику на «ты», `parent` —
родителю на «вы» и о ребёнке по имени. Требование ТЗ F3: правило действует
во всех сообщениях, включая напоминания, уведомления и ответы помощника,
поэтому словарь общий у мини-приложения и бота (ТЗ §13.1).

## Формат

Плоские ключи с точкой, без вложенности — так Go разбирает файл в четыре строки:

```go
type Text struct {
    Kid    string `json:"kid"`
    Parent string `json:"parent"`
}

//go:embed texts.json
var textsJSON []byte

var texts map[string]Text
```

## Подстановки

| Плейсхолдер | Что подставляется |
| --- | --- |
| `{student}` | имя ученика (`trajectories.student_name`) |
| `{me}` | имя того, кто смотрит (`users.first_name`) |
| `{name}` | имя третьего лица: кто отметил, кто предложил, кого удалили |
| `{creator}` | имя создателя траектории |
| `{names}` | перечисление имён через запятую |
| `{count}` | число |
| `{date}`, `{month}` | уже отформатированная дата или месяц |
| `{direction}`, `{grade}`, `{region}`, `{subject}`, `{note}`, `{stage}`, `{title}` | подстановки из данных экрана |

Подстановка — простая замена `{ключ}`, без условий и без выбора формы по числу.

## Два запрета

1. **В словаре нет разметки.** Где в прототипе фрагмент выделен жирным — либо
   два ключа, либо выделение делает вёрстка. Иначе словарь начнёт обрастать
   HTML и станет непригоден для бота.
2. **Склонение числительных — не дело словаря.** «4 дня» собирает
   `plural()` в `apps/web/src/lib/deadline.ts`, в ключе стоит только `{count}`.

## Отличия от прототипа

- **«Отметил(а) {name}» вместо «Отметила Ольга».** MAX отдаёт только имя,
  пола пользователя в `initDataUnsafe.user` нет, угадывать по имени ненадёжно.
  Форма с «(а)» — та же, что ТЗ §3.2 использует для «добавил(а) <имя>».
- **Пустые состояния и ошибки тоже озвучены.** В прототипе на экране ученика
  местами остался текст на «вы» («Сбросьте фильтры»); ТЗ F3 требует
  единообразия во всех сообщениях, поэтому у таких ключей разные варианты.

## Проверка

Тест `apps/web/src/voice/dict.test.ts` проходит по всему файлу: у каждого ключа
есть оба варианта, и каждый `{плейсхолдер}` входит в список выше.
