# Лендинг «Траектории» — пакет для разработки

Этот пакет — всё, что нужно, чтобы сверстать лендинг «Траектории» один в один с макетами. Макеты собраны на холсте и выгружены в обычные HTML-страницы.

## Что в пакете

```
traektoriya-landing/
├── BRIEF.md                    ← этот файл: задача и правила
├── html/
│   ├── desktop-1440.html       ← макет десктопа (источник истины для ≥1024 px)
│   └── mobile-390.html         ← макет телефона (источник истины для ≤767 px)
├── screenshots/
│   ├── desktop-1440-full.png   ← вся страница целиком
│   ├── mobile-390-full.png
│   ├── desktop-sections/       ← каждый раздел отдельно, 1x
│   └── mobile-sections/        ← каждый раздел отдельно, 2x
├── assets/
│   ├── screens/                ← скриншоты продукта для телефонов на лендинге (PNG 2x, 584×1226)
│   ├── logo/                   ← логотип (цветной и белый), знак, иконка приложения, OG-картинка
│   └── icons/                  ← 8 линейных иконок бренда (SVG, stroke = currentColor)
├── fonts/                      ← Onest и Unbounded, variable woff2 (самостоятельный хостинг)
├── tokens/
│   ├── tokens.json             ← токены бренд-системы (цвета светлой и тёмной темы, типографика, отступы, радиусы, тени)
│   └── tokens.css              ← те же токены как CSS-переменные + @font-face
└── source-canvas/              ← исходники артбордов холста (.dc.html) — только для справки, формат редактора
```

**Источник истины — `html/desktop-1440.html` и `html/mobile-390.html`.** Откройте их в браузере: вёрстка, тексты, отступы, цвета и поведение там финальные. Все стили inline, поэтому значения можно брать прямо из разметки. Скриншоты — для визуальной сверки.

## Задача

Сверстать **одну адаптивную страницу** лендинга:

- **≥1024 px** — раскладка как в `desktop-1440.html`. Контейнер контента 1280 px с полями 80 px на ширине 1440; на меньших десктопах поля сжимаются, сетки остаются.
- **≤767 px** — раскладка как в `mobile-390.html`. Поля 20 px, карточки в одну колонку (кроме блока цифр — 2×2).
- **768–1023 px** — промежуточная: сетки из 3–4 колонок в 2 колонки, панели «Трекер» и «Помощник» — друг под другом.
- Ширины в макетах фиксированные (1440 и 390) — в продакшене вёрстка должна быть резиновой: `max-width`, `flex`/`grid`, `clamp()` для крупных заголовков.
- Стек — на ваш выбор. Если лендинг живёт отдельно от мини-приложения, достаточно статического HTML/CSS/JS или Astro/Vite. Если в монорепозитории проекта — отдельное приложение, не трогая `apps/web`.

## Поведение

1. **Вопросы (`#faq`)** — аккордеон, одновременно открыт один вопрос, первый открыт по умолчанию. Кнопка вопроса: `aria-expanded`, значок «+» / «−». Реализация-образец — в конце HTML-файлов.
2. **Чередование экранов** в панелях «Ни одной пропущенной регистрации» и «ИИ-помощник, который не выдумывает»: два скриншота лежат друг на друге и плавно сменяются (opacity, 0,6 с) каждые 3,5 с, обе панели синхронно. Вместе со скриншотом меняются плашки рядом:
   - трекер: «3 дня до срока» ↔ «Google и Apple Календарь»;
   - помощник: «Факт — ответ со ссылкой на источник» ↔ «Данных нет — и ссылка на источник».
   При `prefers-reduced-motion: reduce` — без анимации (показывать первый экран). В HTML это классы `swap-a` / `swap-b` и класс `alt` на `<body>`.
3. **Все кнопки «Открыть в MAX», «Открыть бота», «Начать в MAX»** ведут на `https://max.ru/t356_hakaton_max_bot`.
4. **Меню** — якорные ссылки с плавной прокруткой; учитывайте высоту шапки (`scroll-margin-top`). На телефоне в макете есть кнопка-бургер — нужно выпадающее меню с теми же пунктами.
5. **Карточки шагов и панели возможностей** обрезают скриншот телефона снизу (`overflow: hidden` у карточки, телефон спозиционирован абсолютно) — это намеренно.

## Дизайн-система

Подключите `tokens/tokens.css` и используйте переменные вместо «сырых» значений.

- **Шрифты**: Unbounded — только заголовки и крупные числа (от 20 px), Onest — всё остальное. Хостить самим из `fonts/` (Google Fonts в РФ может быть нестабилен).
- **Основные цвета**: фон `--color-surface` #F6F5FB, текст `--color-ink` #17142A, вторичный текст `--color-ink-muted` #625C78, бренд `--color-brand` #6B2BFF, акценты `--color-cyan` #7FEAF7 и `--color-pink` #FF3D8B.
- **Дополнительные оттенки**, которые есть в макете, но ещё не в токенах, — заведите их как токены:
  - `#DCCFFF` — ступени на лиловом фоне; `#8F63FF`, `#7D4DFF`, `#D6C8FF` — оттенки фиолетового в декоре;
  - `#DDF7FB` / `#0B5F6B` / `#B8EEF5` — бирюзовая карточка цифр (фон / текст / декор);
  - `#FFC6DB`, `#FF8DBE` — розовый декор; `#FFE3A3`, `#FFC94D` — жёлтый декор;
  - `#E8E0FF` — вторичный текст на фиолетовом; `#CFC9E3` — вторичный текст на тёмном; `#3A3450` — текст на лиловом;
  - `#2A2148`, `#2A1F52`, `#A68BFF` — тёмная панель помощника.
- **Радиусы**: карточки 20–28 px, крупные панели 32–40 px, кнопки 14 px, плашки 8 px или полностью скруглённые.
- **Тени** — только у «парящих» элементов (телефоны, плашки поверх телефонов): `filter: drop-shadow(...)` для скриншотов с прозрачными углами, `box-shadow` для плашек.

**Правила бренда:**
- Без градиентов в интерфейсе лендинга. Градиент есть только на кнопках внутри скриншотов продукта — это часть продукта, не лендинга.
- Без эмодзи в заголовках.
- Мотив «ступени» (квадраты по сетке 8 px, всегда поднимаются слева направо) — декор, одна «лестница» на панель.

## Картинки

- Скриншоты в `assets/screens/` — PNG 2x (584×1226, прозрачные углы у рамки телефона). На лендинге они выводятся шириной 200–290 px. Для продакшена сделайте WebP/AVIF и `srcset`, `loading="lazy"` для всего ниже первого экрана.
- `alt` для каждой картинки есть в HTML — используйте их.
- Декоративные SVG (ступени, медаль, шапка, календарь, иконки ролей) — inline, с `aria-hidden="true"`.
