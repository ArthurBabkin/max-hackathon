# Онбординг v2 — задачи

Спецификация — [`SPEC.md`](SPEC.md), причины решений — [`DECISIONS.md`](DECISIONS.md).
Все задачи мержатся в `master` через PR. Срок — **29.09 вечером** всё слито и
выкачено (Deploy functions + Deploy web), 30.09 — запас.

## Правила для каждой задачи

1. Ветка от свежего `master`: `git fetch origin && git switch -c feat/onb2-<N>-<slug> origin/master`.
   Текущая локальная ветка `chore/dev-bot-script` (2 коммита про `dev-bot.sh`)
   — отдельная история, в задачи её не тащить.
2. Не коммитить неотслеживаемые файлы корня (`HANDOFF.md`,
   `DATASET_C_NOTES.md`, `olimpiady_spravochnik.json`, `build/`,
   `dataset_c_src/`, `apps/bot/.maxemu/`).
3. Перед PR: `make check`; если задача трогает базу или бот — `make test-db`.
4. Тексты — только через `packages/shared/texts/texts.json`, оба голоса.
5. В описании PR — номер задачи, разделы SPEC, что проверено руками
   (`apps/bot/scripts/dev-bot.sh` или `make bot-poll`).
6. Если SPEC противоречит коду или неясен — остановиться и спросить Влада, не
   придумывать. Решение потом дописать в `DECISIONS.md`.
