# Как запустить работу в Claude Code

Claude Code читает `CLAUDE.md` в корне сам. Дальше — один промпт на задачу, одна
сессия и одна ветка на задачу. Порядок и зависимости — в `TASKS.md`.

## Первый запуск (T1)

```
Прочитай docs/onboarding-v2/README.md, TASKS.md, DECISIONS.md и разделы SPEC.md, на которые ссылается задача T1.
Сделай T1: создай ветку от свежего origin/master, сначала покажи план (какие файлы, что в миграции, какие тесты),
дождись моего «ок», потом реализуй. В конце прогони make check и make test-db и покажи, что проверено.
Если SPEC противоречит коду или что-то неясно — спроси, не придумывай.
```

## Следующие задачи

Тот же промпт с другим номером. Рекомендуемый порядок для Влада:

1. `T1` → `T3` → `T2`
2. `T5` → `T6` → `T4`
3. `T9` → `T7` → `T8`
4. `T10` (если успеваем) → `T12`

Артур параллельно берёт `T11`, как только T1 в `master`.

## После каждой задачи

```
Задача Tn готова? Сверь с критериями готовности в TASKS.md по пунктам, перечисли, что не сделано.
Если по ходу приняли решение, которого нет в DECISIONS.md, — допиши его туда.
Закоммить и открой PR в master с описанием: задача, разделы SPEC, что проверено руками.
```

## Финальная проверка (29.09)

```
Пройди весь онбординг из docs/onboarding-v2/SPEC.md через apps/bot/scripts/dev-bot.sh за ученика и за родителя,
по всем веткам из «Финального флоу» (README онбординга). Составь список расхождений со SPEC, ничего не исправляя.
```
