# Онбординг v2 — точка входа

Переделка онбординга бота и подбора олимпиад. Решения приняты 25.09.2026
(Влад + Claude в Cowork). Код нужно слить и выкатить до **29.09 вечером**:
30.09 — запас, с 30.09 по 14.10 код заморожен.

## Что читать и в каком порядке

| Файл | Что там | Когда читать |
|---|---|---|
| [`TASKS.md`](TASKS.md) | Список задач, порядок, зависимости, критерии готовности | Первым: из него берётся задача |
| [`SPEC.md`](SPEC.md) | Поведение каждого шага, ветки, тексты kid/parent, payload, схема БД, скоринг | Перед каждой задачей — разделы, на которые она ссылается |
| [`DECISIONS.md`](DECISIONS.md) | Почему что-то добавили или убрали | Когда хочется «вернуть как было» или сделать иначе |
| [`KICKOFF.md`](KICKOFF.md) | Готовые промпты для Claude Code | Чтобы запустить работу |

**Источник правды — `SPEC.md`.** Макеты на холсте иллюстрируют поведение, но
тексты и падежи в SPEC точнее (например, на холсте «В Набережных Челнах», а в
SPEC — «Только Набережные Челны», чтобы не склонять названия городов).

## Макеты

Холст «Онбординг Траектории — флоу» в claude.ai (артефакт
`https://claude.ai/artifact/BBLKfef3GvbVhqgERqsBZg`, доступ даёт Влад). Внизу
холста — «Финальный флоу» со всеми ветками. Коды экранов в SPEC (`R1`, `A2`,
`V3`…) — это названия артбордов на холсте.

| Ряд | Экраны |
|---|---|
| Направления и интересы | A1, A2, A3 |
| Опыт и итог | B1, B2 (ученик), B3 (родитель) |
| Подбор в мини-приложении | C1 (сейчас), C2 (после) |
| Регион | R1–R5 |
| Где учиться | W1–W3 |
| Вузы | V1–V3 |
| Родитель | P1–P3 |

## Короткое резюме изменений

1. «Не знаю — помоги выбрать» → два вопроса об интересах → бот предлагает 2–3 направления.
2. Новый вопрос об опыте в олимпиадах; от него зависит, какой уровень олимпиад наверху.
3. Регион вводится текстом (город или регион, с опечатками), запасной путь — по алфавиту, а не по федеральным округам.
4. «Где учиться»: свой город или свой регион, несколько мест сразу.
5. Вузы: подписи «вуз · город», поиск по народным названиям, честный ответ, если направления в выбранных местах нет.
6. Итог: профиль на подтверждение с правкой в боте, затем «Подобрали N олимпиад» и кнопка в мини-приложение.
7. Родитель может передать вопросы об интересах ребёнку.
8. Скоринг: вес уровня по опыту, «потенциальная» льгота без выбранных вузов, не больше 2 олимпиад на предмет, вес льготы по классу.
